apps/api (The Backend)
    config/: Houses connection logic to PostgreSQL or MongoDB, making sure database pools are managed properly.
    middleware/: Acts as security checkpoints. For example, authMiddleware.ts intercepts incoming requests, verifies JWT user tokens, and blocks unauthorized access before code reaches the controllers.
    controllers/: Contains business logic. When POST /api/tasks is called, taskController.ts extracts the task data, runs validation, and executes the database insert.
    models/: Defines data shape and validation rules (like the Mongoose schemas built earlier).
apps/web (The Frontend)
    components/: Small, stateless UI elements used throughout the app (e.g., custom buttons, inputs).
    features/: Houses domain-specific UI components grouped together. The TaskBoard component, task drag-and-drop logic, and filter controls live here.
    services/: Configures API communication logic (like setting up Axios base URLs and auth headers) so individual components don't repeat raw fetch calls.
packages/shared-types (The Shared Layer)
    Commercial apps use TypeScript across the entire stack. This shared package exports interfaces like interface Task { id: string; title: string; status: TaskStatus }.
    Importing this single definition into both the backend API and frontend UI guarantees that if a field name changes on the server, the frontend highlights the mismatch at compile time before hitting production.
